# Simple DCA & Portfolio Tracker

แอปบันทึกการลงทุนแบบ DCA (ทยอยซื้อเป็นงวด) ช่วยดูสัดส่วนพอร์ตเทียบกับเป้าหมาย แนะนำว่าเดือนนี้ควรเติมเงินให้ตัวไหน และติดตามผลตอบแทนแบบเข้าใจง่าย ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ฟรี ไม่ต้องสมัครสมาชิก

> ข้อมูลเพื่อการศึกษาและเครื่องมือช่วยจดบันทึกเท่านั้น ไม่ใช่คำแนะนำการลงทุน

---

## 1) เริ่มใช้งานทันที (ไม่ต้องติดตั้ง)

เปิดลิงก์: **https://dca-tracker-seven.vercel.app**

**เพิ่มลงหน้าจอมือถือให้เปิดเหมือนแอป**
- iPhone (Safari): กดปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
- Android (Chrome): กดเมนู ⋮ → "เพิ่มไปยังหน้าจอหลัก" หรือ "ติดตั้งแอป"

ไม่ต้องล็อกอิน ข้อมูลของคุณเก็บในเบราว์เซอร์ของเครื่องที่ใช้อยู่เท่านั้น (ดูหัวข้อ "ข้อมูลของคุณ" ด้านล่าง)

## 2) วิธีใช้งานใน 5 ขั้นตอน

1. **ตั้งพอร์ต** (แท็บ "พอร์ต")
   แอปให้พอร์ตตัวอย่างมา 5 รายการ ปรับได้ตามใจ: แก้ชื่อ ใส่สัญลักษณ์ราคา ตั้งเป้า % ให้รวมกันได้ 100% (ถ้าไม่ครบจะมีข้อความเตือนสีส้ม)
2. **ใส่สัญลักษณ์ราคา** (ถ้าอยากให้แอปดึงราคาให้)
   พิมพ์ตามแบบ Yahoo Finance เช่น `VOO`, `NVDA`, `TISCO.BK` (หุ้นไทยต่อท้าย `.BK`) แล้วคลิกออกจากช่อง แอปจะดึงชื่อและราคามาให้ ถ้าเป็นทอง ตราสารหนี้ หรือเงินสด ปล่อยว่างไว้แล้วกรอกมูลค่าเองที่หน้าภาพรวม
3. **ตั้งงบประจำเดือน** (แท็บ "ซื้อ")
   ใส่จำนวนเงินที่จะลงทุนต่อเดือน ระบบจำค่าไว้ให้ ไม่ต้องกรอกใหม่ทุกเดือน
4. **ดูคำแนะนำแล้วกดซื้อ** (แท็บ "ซื้อ")
   ระบบแนะนำว่าตัวไหนควรได้เงินเท่าไร กด "บันทึกซื้อ" หลังซื้อจริงกับโบรกเกอร์ แล้วยอดเหลือของเดือนนี้จะลดลงให้เอง
5. **ติดตามผล** (แท็บ "ภาพรวม")
   ดูมูลค่ารวม กำไร/ขาดทุน และสัดส่วนปัจจุบันเทียบเป้า

## 3) แต่ละหน้าทำอะไร

### ภาพรวม
- มูลค่ารวม เงินลงทุนสะสม และกำไร/ขาดทุน
- แถบสรุปว่าพอร์ตอยู่ในช่วงยอมรับหรือมีตัวที่หลุดเป้า
- โดนัทสองวง: **วงนอก = สัดส่วนตอนนี้ วงใน = สัดส่วนเป้า**
- สรุปแยกตาม "ประเภทสินทรัพย์" และ "ถัง (ระยะเวลาลงทุน)"
- การ์ดแต่ละสินทรัพย์ พร้อมสถานะสี: เขียว = ใกล้เป้า / ฟ้า = เกินเป้า / ส้ม = ต่ำกว่าเป้า / แดง = ขาดมาก
- ปุ่ม "รีเฟรชราคา" (แอปรีเฟรชเองทุก 5 นาทีขณะเปิดหน้านี้อยู่)
- ตัวที่ไม่มีราคาสด จะมีช่องให้กรอก "มูลค่าตอนนี้" เองจากแอปโบรกเกอร์

### ซื้อ
- **งบประจำเดือน:** แสดงยอดที่ซื้อไปแล้วและยอดเหลือของเดือนนี้ ขึ้นเดือนใหม่รีเซ็ตเอง
- **ระบบแนะนำ:** เติมให้ตัวที่ต่ำกว่าเป้าก่อน ที่เหลือกระจายตามสัดส่วนเป้า โดยไม่เกินเพดานที่ตั้งไว้ และไม่ลงเงินเพิ่มในตราสารที่ใกล้ครบกำหนด
- **ป้องกันกดพลาด:** มีกล่องยืนยันก่อนบันทึก กันแตะซ้ำ และเตือนถ้าเพิ่งบันทึกรายการเดียวกันไป
- **บันทึกเอง:** เลือกวันที่ สินทรัพย์ จำนวนเงิน (จำนวนหน่วยและราคาต่อหน่วยใส่หรือไม่ใส่ก็ได้)

### ประวัติ
รายการซื้อทั้งหมด เรียงใหม่ไปเก่า กด "ลบ" ถ้าบันทึกผิด (ยอดงบเดือนนั้นจะคืนให้เอง)

### พอร์ต
- **ช่วงยอมรับ:** กำหนดเองได้ (ค่าเริ่มต้น ±2%)
- **สัดส่วนตามประเภท:** ปรับเป้าทั้งประเภทในช่องเดียว ระบบกระจายลงแต่ละตัวให้
- **ต่อสินทรัพย์:** ชื่อ, สัญลักษณ์ราคา, ประเภท, ถัง, เป้า %, เพดานสูงสุด %, วันครบกำหนด (ตราสารหนี้/เงินสด), เหตุผลที่ถือ
- **เปลี่ยนหุ้น:** เปลี่ยนตัวในช่องเดิมโดยคงเป้าและหมวดไว้ (เลือกได้ว่าจะย้ายประวัติการซื้อมาด้วยหรือไม่)
- เพิ่ม/ลบสินทรัพย์ และสำรอง/นำเข้าข้อมูล

## 4) แนวคิดที่ควรรู้

- **DCA:** ทยอยลงทุนเท่า ๆ กันเป็นงวด แทนการซื้อก้อนเดียว ลดความเสี่ยงจากการเลือกจังหวะผิด
- **ช่วงยอมรับ (±%):** ถ้าสัดส่วนจริงอยู่ในช่วงใกล้เป้า ไม่ต้องปรับ ช่วยไม่ให้ปรับพอร์ตถี่เกินไป เมื่อหลุดช่วง แอปแนะนำให้ "เติมเงินใหม่ให้ตัวที่ขาด" ก่อน ไม่จำเป็นต้องขายของเดิม
- **ประเภท / ถัง:** ประเภทบอกว่าคืออะไร (หุ้น ตราสารหนี้ ทอง เงินสด กองทุน) ส่วนถังบอกว่าเงินก้อนนั้นไว้ใช้เมื่อไร (Safety 0-2 ปี / Dividend 2-10 ปี / Core 10 ปีขึ้นไป / Growth 1-5 ปี เสี่ยงสูง)
- **เพดานสูงสุด:** กันไม่ให้ตัวใดตัวหนึ่งเกินสัดส่วนที่ตั้งไว้ เช่น ทองไม่เกิน 10%

## 5) ข้อมูลของคุณ

- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ ไม่ถูกส่งไปที่ใด เจ้าของแอปไม่เห็นข้อมูลของคุณ
- **ข้อมูลไม่ข้ามเครื่องและไม่ข้ามเบราว์เซอร์** (เปิดบนมือถือกับคอมจะเป็นคนละชุด) เว้นแต่เจ้าของเซิร์ฟเวอร์เปิดระบบซิงค์ (ดูหัวข้อ 7)
- **ถ้าล้างข้อมูลเบราว์เซอร์ เปลี่ยนเครื่อง หรือใช้โหมดไม่ระบุตัวตน ข้อมูลจะหาย** จึงควรสำรองเป็นระยะ

**วิธีสำรอง:** แท็บ "พอร์ต" → เลื่อนลงล่างสุด → กด "บันทึกเป็นไฟล์สำรอง"
- มือถือ: จะเปิดหน้าต่างแชร์ ให้เลือกบันทึกลง Files, Google Drive, iCloud หรือส่งเข้าแชตตัวเอง
- คอมพิวเตอร์: ดาวน์โหลดไฟล์ `dca-backup-วันที่.json` ลงเครื่อง
- ทางเลือก: กด "คัดลอกข้อมูลสำรอง" แล้ววางเก็บในโน้ตหรือแชตตัวเอง

**วิธีนำข้อมูลกลับมา / ย้ายเครื่อง:** แท็บ "พอร์ต" → "นำเข้าจากไฟล์สำรอง" เลือกไฟล์ `.json` (หรือกด "วางจากคลิปบอร์ด" แล้วกด "นำเข้าจากข้อความ") ข้อมูลเดิมในเครื่องนั้นจะถูกแทนที่ทั้งหมด

แอปจะเตือนที่หน้า "ภาพรวม" ถ้ายังไม่เคยสำรอง หรือไม่ได้สำรองเกิน 30 วัน และขอให้เบราว์เซอร์เก็บข้อมูลถาวร (เบราว์เซอร์เป็นผู้ตัดสินใจ ไม่รับประกัน) สถานะดูได้ในหัวข้อสำรองข้อมูล ไฟล์สำรองมีจำนวนเงินและประวัติการซื้อของคุณ เก็บไว้ในที่ส่วนตัว

## 6) ข้อจำกัด

- **ราคาไม่ใช่เรียลไทม์:** ดึงจาก Yahoo Finance (แหล่งไม่เป็นทางการ) อาจช้ากว่าตลาดหลายนาที และตอนตลาดปิดจะเป็นราคาปิดล่าสุด ถ้าดึงไม่ได้ แอปจะให้กรอกมูลค่าเอง ราคาจริงตอนซื้อให้ยึดตัวเลขจากโบรกเกอร์
- **มูลค่าจากราคาสด** ใช้ได้เมื่อทุกรายการซื้อของตัวนั้นมี "จำนวนหน่วย" (รายการที่บันทึกหลังตั้งสัญลักษณ์ราคา แอปคำนวณหน่วยให้เอง) ตัวที่ไม่มีหน่วยให้กรอกมูลค่าเอง
- ราคาหุ้นต่างประเทศแปลงเป็นบาทด้วยอัตรา USD/THB ที่ดึงมาพร้อมกัน ยังไม่รองรับสกุลเงินอื่น
- ยอด "ซื้อไปแล้วเดือนนี้" นับทุกรายการซื้อของเดือนนั้น
- ยังไม่มีบันทึกปันผลและกราฟย้อนหลัง

## 7) ติดตั้งเป็นของตัวเอง (สำหรับคนที่อยากโฮสต์เอง ฟรีทั้งหมด)

ต้องมีบัญชี GitHub และโปรแกรม VS Code

### 7.1 ลองในเครื่อง
1. ดาวน์โหลดโปรเจกต์ แตกไฟล์ และเปิดโฟลเดอร์ใน VS Code (ต้องเห็น `index.html` ที่ระดับบนสุด)
2. ติดตั้งส่วนเสริม **Live Server** แล้วคลิกขวาที่ `index.html` → Open with Live Server
   (ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิกไฟล์ตรง ๆ จะไม่ทำงาน)
3. ในเครื่องจะยังไม่มีราคาสด เพราะ `/api/quote` ทำงานบน Vercel (ทดสอบเต็มระบบได้ด้วย `npx vercel dev` ถ้าติดตั้ง Node.js)

### 7.2 ขึ้นออนไลน์ด้วย GitHub + Vercel
1. VS Code → Source Control → Initialize Repository → Commit → Publish to GitHub
2. เข้า vercel.com → Sign up ด้วย GitHub
   **เลือกแพ็กเกจ "Hobby / personal projects" (ฟรี)**
3. Add New → Project → เลือก repo → Application Preset เลือก **Other** → Deploy
4. ได้ลิงก์ `xxx.vercel.app` ใช้งานและแชร์ได้ทันที ทุกครั้งที่ Push โค้ดใหม่ Vercel จะ deploy ให้เอง

### 7.3 เปิดซิงค์ข้ามเครื่อง (ไม่บังคับ)
1. สมัคร supabase.com ด้วย GitHub → New project
2. SQL Editor → วางเนื้อหาไฟล์ `supabase.sql` → Run
3. Project Settings → API → คัดลอก Project URL และ anon public key ใส่ในไฟล์ `js/config.js` (anon key เปิดเผยได้ เพราะมี RLS กันไม่ให้ใครเห็นข้อมูลของคนอื่น) แล้ว Push
4. Authentication → URL Configuration → ใส่ลิงก์ Vercel ใน Site URL และ Redirect URLs
5. เปิดล็อกอินอย่างน้อยหนึ่งแบบที่ Authentication → Providers
   - **GitHub:** GitHub → Settings → Developer settings → OAuth Apps → New (Homepage = ลิงก์ Vercel, Callback = `https://<project-id>.supabase.co/auth/v1/callback`) แล้วนำ Client ID/Secret ไปใส่ใน Supabase
   - **Google (แนะนำถ้าจะแชร์ให้คนทั่วไป):** สร้าง OAuth Client ID (Web) ใน Google Cloud Console ใช้ Callback เดียวกัน แล้วนำ Client ID/Secret ไปใส่ใน Supabase

เมื่อตั้งค่าแล้ว แท็บ "พอร์ต" จะมีปุ่มล็อกอิน ข้อมูลแต่ละคนแยกกัน และใช้ข้อมูลที่แก้ไขใหม่กว่าเป็นหลัก

## 8) โครงสร้างโปรเจกต์ (สำหรับนักพัฒนา)

```
index.html            หน้าเปล่า โหลด js/main.js
css/style.css         หน้าตา
api/quote.js          Vercel function ดึงราคา Yahoo Finance
supabase.sql          ตารางซิงค์ข้อมูล
js/config.js          ค่า Supabase (เว้นว่าง = ปิดซิงค์)
js/main.js            ประกอบทุกส่วนเข้าด้วยกัน
js/models/            Asset, Transaction, Portfolio (ข้อมูล + คำนวณมูลค่า)
js/core/              RebalanceEngine (ช่วงยอมรับ เพดาน ระบบแนะนำ)
js/services/          StorageService, PriceService, SyncService
js/ui/                App (ตัวประสาน), View (คลาสแม่), Home/Buy/History/Setup
```

แก้อะไรที่ไหน: กติกา rebalance → `core/` · เพิ่มช่องข้อมูล → `models/` + `ui/SetupView.js` · เพิ่มหน้าใหม่ → สร้างคลาสสืบทอด `View` แล้วลงทะเบียนใน `ui/App.js` · เปลี่ยนแหล่งราคา → `PriceService.js` + `api/quote.js`

## คำเตือน

แอปนี้เป็นเครื่องมือช่วยจดบันทึกและคำนวณสัดส่วนเท่านั้น ไม่ได้รับประกันผลตอบแทน ไม่ได้เป็นคำแนะนำการลงทุน และตัวเลขราคาอาจคลาดเคลื่อนหรือล่าช้า ผู้ลงทุนควรศึกษาข้อมูลเพิ่มเติมและพิจารณาความเหมาะสมกับตนเองก่อนตัดสินใจ
